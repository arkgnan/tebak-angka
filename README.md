## 📌 Latar Belakang & Misi Edukasi

Judi online (judol) dirancang secara matematis dan psikologis agar pemain **pasti bangkrut 100%** dalam jangka panjang. Banyak masyarakat terjebak karena tidak memahami cara kerja algoritma server bandar:

1. **Ilusi Peluang Adil (Fair Chance Illusion)**: Mengira probabilitas kemenangan 50:50, padahal server telah memangkas peluang hingga di bawah 10%.
2. **Umpan Dopamin (Baiting)**: Bandar sengaja memberi 1 kemenangan kecil setelah pemain dibuat kalah berturut-turut agar tidak berhenti bertaruh.
3. **Efek Near-Miss (Nyaris Menang)**: Roda atau rol slot sengaja dihentikan 1 milimeter di samping Jackpot untuk memicu respons otak yang sama seperti saat menang.
4. **Ilusi Kontrol (Illusion of Control)**: Pemain merasa bisa mengendalikan kemenangan (seperti tombol tarik saldo di game crash), padahal titik ledak sudah ditetapkan di server sejak tombol mulai diklik.

Aplikasi **Rungkad** menghadirkan **6 simulator permainan kasino online** menggunakan kredit virtual tanpa uang sungguhan. Setiap kekalahan dan kemenangan disertai penjelasan ilmiah yang membongkar trik bandar secara transparan.

## 🕹️ 5 Permainan Simulasi Edukasi

### 1. 🎯 Tebak Angka (Higher / Lower)
- **Trik yang Dibongkar**: Manipulasi Peluang & *Baiting*.
- **Cara Kerja**: Pemain menebak apakah angka berikutnya lebih tinggi atau lebih rendah dari angka dasar. Algoritma server memprogram agar pemain dipaksa kalah 3–5 kali beruntun sebelum diberi 1 kali umpan kemenangan kecil, serta mencegah pemain menang berturut-turut.

### 2. 🚀 Roket Boncos (Crash / Aviator)
- **Trik yang Dibongkar**: *Illusion of Control* & *Jebakan Keserakahan*.
- **Cara Kerja**: Multiplier roket naik secara perlahan memancing ketamakan pemain. Padahal titik ledak (*crash point*) sudah dikunci di server sejak detik pertama peluncuran (55% meledak instan di bawah 1.15x).

### 3. 🎡 Roda Putar Ilusi (Lucky Wheel)
- **Trik yang Dibongkar**: *Near-Miss Effect* (Nyaris Menang).
- **Cara Kerja**: 52% putaran diatur agar jarum berhenti tepat di samping segmen **JACKPOT x10** (pada kotak *Boncos* atau *Zonk Lagi*), menipu alam bawah sadar pemain bahwa kemenangan sudah sangat dekat.

### 4. 🎰 Slot Rungkad 777 (3-Reel Classic Slot)
- **Trik yang Dibongkar**: Mitos Bohong "Pola & Jam Gacor" serta Scatter Bayangan.
- **Cara Kerja**: Mesin slot menggunakan RNG terkunci dengan house edge ekstrem. Reel 1 & 2 sering sengaja dimunculkan angka `7️⃣`, namun reel ke-3 dihentikan pada bom/lemon. Postingan medsos tentang jam gacor dibongkar sebagai rekayasa affiliator bandar.

### 5. ✌️ Suit Bandar Licik (Janken / Batu Gunting Kertas)
- **Trik yang Dibongkar**: *Taruhan Terkirim Dulu ke Server*.
- **Cara Kerja**: Mensimulasikan pemain yang harus memilih Batu `✊`, Gunting `✌️`, atau Kertas `✋` terlebih dahulu. Pilihan dikirim ke server sebelum tangan bandar dikocok, sehingga algoritma bandar selalu mengeluarkan lawan yang mengalahkan pemain.

### 6. 📈 Trading Binary Option (Simulasi Binomo)
- **Trik yang Dibongkar**: *Manipulasi Grafik dan Waktu Entry*.
- **Cara Kerja**: Mensimulasikan grafik harga aset yang selalu bergerak melawan arah taruhan pemain. Candle sering muncul hanya dalam hitungan milidetik di antara waktu entry dan closing untuk menipu pemain.

## ✨ Fitur-Fitur Utama

- **📊 Dashboard Statistik & Simulasi Kerugian**:
  - Menghitung total putaran, tingkat kemenangan (*win rate*), dan simulasi uang rupiah yang hangus jika bertaruh dengan uang asli.
  - Tab swipe navigasi antara Beranda Statistik dan Menu Permainan.
- **📜 Riwayat Putaran Terakhir (Audit Trail)**:
  - Mencatat detail tiap putaran dari semua 6 game dengan status Menang, Kalah, atau Balik Modal.
  - Tombol expand *"Lihat Lebih Banyak"* untuk meninjau riwayat putaran sebelumnya.
- **💡 Fakta Ilmiah Acak**:
  - Bank edukasi 10 fakta ilmiah & psikologi judi online yang berganti otomatis setiap aplikasi dibuka.
- **🪙 Sistem Kredit & Iklan Reward AdMob**:
  - Otomatis menayangkan video reward iklan AdMob saat kredit habis tanpa perlu mencari tombol manual.
  - Tombol Top Up aktif berwarna kuning keemasan (`#FFB300`) seragam di semua permainan.
- **🔊 Efek Suara & Getar Haptic Interaktif**:
  - Dilengkapi 8 aset audio WAV lokal (`btn_click`, `spin_tick`, `win_chime`, `jackpot`, `loss_buzz`, `rocket_fly`, `explosion`, `clash`).
  - Haptic feedback getar nyata (`react-native Vibration`) pada setiap interaksi, putaran roda/slot, kemenangan, dan ledakan.
- **🔐 Autentikasi Google Sign-In & Akun Tamu**:
  - Dukungan login resmi Google Sign-In via Firebase Auth serta mode Tamu (*Guest Mode*).
  - Penyimpanan state lokal aman menggunakan Redux Persist & AsyncStorage.
- **📢 Bagikan Edukasi ke Media Sosial**:
  - Dialog bagikan (*Share Modal*) berisi rekapitulasi statistik rungkad untuk mengedukasi keluarga dan teman.
- **🎨 Desain Premium Dark Mode**:
  - UI modern berbasis palet warna gelap `#0B121E`, aksen neon cyan `#00E5FF`, kartu kaca (*glassmorphism*), dan transisi layar mulus bebas *splash* putih.

## 🚀 Memulai (Getting Started)

### 📲 Pasang Langsung dari Google Play Store
Bagi Anda yang ingin langsung mencoba aplikasi simulasi edukasi ini tanpa melakukan kompilasi kode sumber:
* **Download Resmi**: [Tebak Angka di Google Play Store](https://play.google.com/store/apps/details?id=com.arkgnan.tebakangka)
* **ID Paket**: `com.arkgnan.tebakangka`

---

### 💻 Menjalankan dari Kode Sumber (Local Development)

#### Prasyarat
- **Node.js**: Versi `>= 18.0.0`
- **JDK**: Java Development Kit 17
- **Android Studio**: Android SDK Build-Tools 34 & Emulator / Device fisik Android
- **Expo CLI**: `npm install -g expo-cli`

#### Langkah Instalasi

1. **Clone repositori**:
   ```bash
   git clone https://github.com/arkgnan/tebak-angka.git
   cd tebak-angka
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```
   *(Script `postinstall` akan otomatis mengaplikasikan semua perbaikan di folder `patches/`)*

3. **Konfigurasi Variabel Lingkungan (`.env`)**:
   Salin template `.env.example` ke `.env`:
   ```bash
   cp .env.example .env
   ```
   *Secara default variabel sudah terisi dengan Google Test Ad IDs resmi agar aman saat dijalankan di emulator atau testing.*

4. **Konfigurasi Firebase & Google Services**:
   Salin template `google-services.json.example`:
   ```bash
   cp google-services.json.example google-services.json
   cp google-services.json.example android/app/google-services.json
   ```
   *(Untuk pengujian Google Sign-In dengan proyek Firebase Anda sendiri, gunakan file `google-services.json` asli dari konsol Firebase Anda).*

5. **Jalankan aplikasi di Android**:
   ```bash
   npx expo run:android
   ```

6. **Validasi kode (Type Check)**:
   ```bash
   npx tsc --noEmit
   ```
